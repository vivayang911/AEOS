# AEOS

## Development disclosure

AEOS is an **AI-assisted software project**. AI coding agents have been used extensively to help analyze the PRD, design and implement code, generate and maintain tests, investigate failures, and draft technical documentation. The human project owner remains responsible for the product requirements, architecture and risk decisions, acceptance of changes, operation of the development environment, and every wallet or DAO confirmation.

AI assistance does not receive custody or execution authority: AEOS and its coding agents do not hold private keys, sign transactions, broadcast arbitrary transactions, or control treasury assets. The repository intentionally preserves deterministic tests, immutable lineage, explicit Mock/live labels, transaction hashes, and strict `PARTIAL` versus `ACCEPTED` status so reviewers can independently verify what was generated, what was executed by the user, and what remains unfinished. No repository claim should be interpreted as proof of unaudited economic accuracy, investment performance, production readiness, or autonomous asset control.
