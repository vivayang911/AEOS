# 安全与合规

## 1. 安全目标

保护国库资产、治理授权、证据完整性、组织数据隔离和审计可用性。AI、外部数据、RPC 和用户输入均视为不可信。

## 2. 主要威胁与控制

| 威胁 | 控制 |
|---|---|
| 提示注入 | 数据/指令隔离、工具白名单、输出 Schema、人工审批 |
| 虚假/过期数据 | 证明验证、新鲜度门槛、冲突检测、快照 |
| 越权执行 | RBAC、链上 Timelock/Safe、合约白名单、限额 |
| 私钥泄漏 | 不入库、KMS/MPC/钱包、轮换与最小权限 |
| 重放/重复执行 | action ID、幂等键、nonce、状态检查 |
| 跨租户泄漏 | RLS、组织过滤、独立缓存键、授权测试 |
| RPC/供应链风险 | 多端点、依赖锁定、SBOM、签名构建产物 |
| 治理攻击 | 门槛、延迟、法定人数、时间锁、Guardian 暂停 |

## 3. 应用安全

- OWASP ASVS 基线；输入校验、输出编码、CSRF/CORS/CSP。
- 会话短期有效，敏感操作重新认证或钱包签名。
- API 限流、异常行为检测和统一脱敏日志。
- 依赖、容器、IaC 和密钥扫描纳入 CI。

## 4. AI 安全

- 模型不能访问私钥、任意网络或任意代码执行。
- 记录模型、提示、工具版本和输入/输出哈希。
- 高影响任务采用双重检查与拒答机制。
- 对注入、数据投毒、越权工具、数字幻觉做持续红队测试。

## 5. 事件响应

严重级别 Sev-1 至 Sev-4。Sev-1 立即暂停执行路径、保护证据、通知多签/治理负责人并启动链上资金保护预案。事后报告包含时间线、影响、根因、修复和验证。

## 6. 合规边界

产品界面声明非个人投资建议；记录数据来源与处理目的；按最小化原则收集个人数据。具体证券、牌照、制裁、隐私和税务要求应由目标司法辖区的专业顾问确认。
