# AEOS 产品需求文档（PRD）

## 1. 版本与范围

- 版本：v1.0 MVP
- 交付目标：可在测试网完成“可信数据 → Agent 建议 → DAO 提案 → 安全执行 → 反馈复盘”的端到端演示。
- 优先级：P0 必须、P1 应有、P2 后续。

## 2. 用户故事

### US-01 连接 DAO（P0）

作为管理员，我可以连接钱包，选择网络并登记 DAO、Governor、Timelock、Safe 和 Treasury 地址。

验收：校验链 ID、地址格式和合约接口；写操作要求签名；配置变更进入审计日志。

### US-02 创建国库策略（P0）

作为财库委员，我可以定义目标稳定币比例、资产白名单、单次/日累计限额、最大滑点、风险阈值和观察周期。

验收：参数有类型、范围、版本和生效时间；冲突参数不可发布；历史版本只读。

### US-03 获取可信证据（P0）

作为研究员，我可以查询跨链余额、资产和市场事件，并看到来源、验证状态、时间和原始证明。

验收：每条证据有唯一 ID；验证失败不进入“已验证”集合；过期状态可见。

### US-04 生成委员会建议（P0）

作为委员，我可以启动分析任务并查看各 Agent 的观点、引用、异议、风险和最终建议。

验收：关键数字必须引用 Evidence ID；缺证据时输出“不足以决策”；输出符合固定 JSON Schema。

### US-05 模拟与风险检查（P0）

作为执行者，我可以在提案前模拟交易和投后资产分布。

验收：展示 gas、滑点、余额变化和所有策略检查；任一硬限制失败则禁止提交。

### US-06 发起与审议提案（P0）

作为提案者，我可以将建议转换为链上/离线治理提案，并附上不可篡改的决策摘要和证据清单。

验收：提案内容哈希与存档一致；状态与链上同步；可查看投票期和法定人数。

### US-07 执行与复盘（P0）

作为运营者，我可以在提案通过和时间锁结束后执行，并查看交易回执、目标偏差与后续建议。

验收：执行前重新模拟；失败可安全重试但不可重复执行；结果写入审计日志。

### US-08 紧急暂停（P0）

作为安全管理员，我可以暂停自动化和合约执行路径。

验收：暂停即时可见；只有指定角色可恢复；暂停不影响只读分析。

## 4. 非功能需求

- 安全：密钥不进入应用数据库；服务间最小权限；敏感配置来自密钥管理服务。
- 性能：普通读取 P95 < 500 ms；缓存证据查询 P95 < 2 s；长任务异步执行。
- 可用性：关键服务月可用率 99.5%；任务可幂等重试。
- 可审计：所有影响决策和资产的操作记录 actor、时间、前后值、关联对象与哈希。
- 可访问性：核心流程符合 WCAG 2.1 AA；支持键盘操作和清晰状态文本。
- 国际化：MVP 支持中文和英文文案框架。

## 5. 关键流程

1. 管理员配置 DAO 与策略。
2. 调度器获取 Attestcoin 数据并创建验证证据快照。
3. Governor Agent 建立分析任务，专业 Agent 并行研究和交叉质询。
4. 风险引擎验证证据覆盖、限额、模拟结果和策略一致性。
5. 用户审批并生成提案；DAO 投票与 Timelock 管理授权。
6. Executor 再模拟并提交交易；Indexer 记录回执。
7. 反馈任务计算目标偏差，更新仪表盘并触发下一周期。

## 6. 状态模型

`DRAFT → ANALYZING → REVIEW_REQUIRED → APPROVED → PROPOSED → VOTING → QUEUED → EXECUTABLE → EXECUTED`

任何阶段可进入 `REJECTED`、`CANCELLED` 或 `FAILED`；失败对象保留原因和可重试标记。

## 7. MVP 页面

- 总览：资产、目标偏差、风险、进行中提案和最新证据。
- Evidence Explorer：搜索、过滤、详情和证明状态。
- Decision Room：Agent 观点、异议、证据和最终建议。
- Strategy Studio：目标、限额、PID 参数、预览和版本。
- Governance：提案列表、详情、投票和执行状态。
- Audit Log：可筛选事件与导出。
- Settings：DAO、网络、角色、集成和暂停开关。

## 8. 发布门禁

- P0 用户故事全部通过端到端测试。
- 合约单元/模糊测试通过，无未处理高危审计问题。
- 关键 API、Agent 输出和链上执行均有审计记录。
- 演示环境可从空配置完成一次测试网闭环。
