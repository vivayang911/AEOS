# AEOS 项目概述

## 1. 产品定义

AEOS 是面向 DAO 的 AI 原生国库治理操作系统。它把可信跨链数据、机构式多 Agent 研究流程、治理授权和智能合约执行连接成可审计闭环：

`目标 → 可信证据 → 分析与风控 → 治理决策 → 链上执行 → 反馈优化`

系统不让大模型直接控制资产。AI 负责整理证据、提出建议和模拟结果；确定性策略、DAO 投票、多签和合约权限负责授权与执行。

## 2. 问题与机会

DAO 国库通常面临数据跨链分散、决策周期长、专业能力不足、提案依据难复核、执行与复盘脱节等问题。通用 AI 虽能提高分析效率，却存在数据过时、幻觉和不可追溯风险。

AEOS 以 Attestcoin 提供的可验证跨链数据为证据底座，让每个重要判断关联 Evidence ID、来源、时间、链与验证状态，并用机构化角色减少单一模型的偏差。

## 3. 目标

- 在 10 分钟内完成一次从目标到可审议建议的分析流程。
- 100% 的关键事实和数字具有可点击证据引用。
- 未经显式治理授权，任何 Agent 都不能转移资产。
- 支持提案、模拟、投票、排队、执行和复盘的完整审计链。
- 在测试网演示至少两条链的数据输入与一条链的国库动作。

## 4. 非目标

- 不承诺收益，不提供面向个人的投资建议。
- MVP 不支持无上限自主交易、高频交易或匿名绕过治理。
- 不替代法律、税务、审计或智能合约安全审计。
- 不在 MVP 内构建通用跨链桥或自有预言机网络。

## 5. 目标用户

- DAO 财库委员会：制定策略、审阅风险、发起提案。
- 代币持有人/委托人：查看证据、讨论并投票。
- 运营与执行者：管理策略参数、模拟、排队和执行。
- 审计员：追踪数据来源、模型输出、授权与链上交易。

## 6. 核心模块

1. Evidence Intelligence：接入、验证、标准化、评分和索引证据。
2. AI Investment Organization：研究、策略、量化、风控、合规和组合 Agent。
3. Governance Hub：策略模板、提案、讨论、投票和时间锁。
4. Treasury Control：PID 建议、约束检查、模拟和合约执行。
5. Audit & Observability：完整事件日志、链上链接、模型与提示版本。

## 7. 核心原则

- Evidence first：关键结论必须先有证据。
- Human/DAO in control：高影响动作必须由治理授权。
- Deterministic guardrails：限额、白名单和紧急暂停在确定性层执行。
- Reproducible decisions：保存输入快照、模型版本和输出哈希。
- Progressive autonomy：从建议模式逐步升级，权限与成熟度绑定。

## 8. 关键指标

| 维度 | 指标 | MVP 目标 |
|---|---|---|
| 可信度 | 关键声明证据覆盖率 | 100% |
| 效率 | 建议生成 P95 | < 10 分钟 |
| 安全 | 未授权链上动作 | 0 |
| 可用性 | 核心 API 可用率 | ≥ 99.5% |
| 治理 | 提案可复现率 | 100% |
| 数据 | 证据验证成功率 | ≥ 99% |

## 9. 风险

- Attestcoin 数据缺失或延迟：标记新鲜度，启用降级与阻断规则。
- Agent 推理错误：多角色交叉质询、结构化输出和证据覆盖检查。
- 合约漏洞：最小权限、时间锁、多签、审计与紧急暂停。
- 治理攻击：法定人数、提案门槛、投票延迟和委托监控。
- 市场极端波动：硬性风险限额优先于 PID/AI 建议。
