# PID 闭环控制设计

## 1. 用途

PID 控制器根据目标状态与观测状态的偏差，产生受限的再平衡建议。例如目标稳定币占比为 40%，当前为 32%，误差为 8 个百分点。PID 不直接交易，输出还需经过策略、风险、治理和执行层。

## 2. 离散公式

```text
e(t) = target(t) - observed(t)
u(t) = Kp·e(t) + Ki·Σ(e·Δt) + Kd·(e(t)-e(t-1))/Δt
```

- P：响应当前偏差。
- I：消除持续偏差，必须防积分饱和。
- D：抑制快速变化，对噪声敏感，应使用滤波导数。

## 3. 输入与输出

输入：目标比例、可信余额/价格快照、时间间隔、历史误差、市场/流动性状态。输出：有符号调整幅度、置信度、分量解释、适用期和证据快照 ID。

## 4. 安全约束

- 输出限幅：单周期和每日最大调整。
- 死区：偏差小于阈值时不动作。
- 变化率限制：防止目标/价格短时跳变导致大额操作。
- Anti-windup：输出饱和或执行受阻时冻结/回算积分项。
- 新鲜度：输入过期或证据无效时输出 0 并告警。
- 风险优先：资产、协议、流动性和滑点硬限制可否决输出。

## 5. 参数治理

每组参数包含版本、适用指标、采样周期、Kp/Ki/Kd、死区、输出上下限和启停状态。变更先回测与仿真，再经治理生效；禁止 Agent 在运行时自行修改参数。

## 6. 仿真场景

- 阶跃目标、缓慢漂移、价格尖峰、数据噪声。
- 执行延迟、交易失败、流动性下降和长时间暂停。
- 比较超调量、稳定时间、累计交易成本、换手率和最大风险敞口。

## 7. MVP 建议

先使用低频（如每日）PI 控制器，默认关闭 D 项；在历史和合成数据上校准，并以建议模式运行。达到稳定性、成本和安全指标后再考虑更高自治级别。
